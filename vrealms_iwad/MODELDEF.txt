// THE VR HANDS -- the owner's hand_final.fbx (from his dxr repo, models/hands/), read by the engine
// itself at load with ufbx (src/common/models/model_fbx.h). No conversion: this IS that file.
//
// ONE FILE, TWO MODELS. "<file>.fbx:<mesh>" picks one skinned mesh of an FBX by its node's name, and
// with it the skeleton its skin binds to (src/common/models/model.cpp FindModel). hand_final.fbx has two:
//   Hand_Low   skinned to the joints under GLOBAL_MAIN_CONTROL_R   -- the RIGHT hand
//   Hand_Low1  skinned to the joints under GLOBAL_MAIN_CONTROL_R1  -- the LEFT hand: the file mirrors it
//              with a -1 X scale on that control, and the model keeps that mirror (it is a left hand)
// Each model has its own 22 joints under the FBX's own names and its own take: every frame of
// "Take 001", 1,279 frames at 60 fps (0 = 0 s ... 1278 = 21.3 s: the joints' baked keys end at frame
// 1277, the controls above them are keyed to 1278). Frame 0 is the scene's rest pose (every finger
// joint at its bind rotation; tools/fbxload_test checks it equals the take at 0 s).
//
// THE FINGERS ARE NOT POSED YET. vr_handpose.cpp turned the fingers toward five baked frames of the
// old converter's files (0 1 3 7 8 = open, point, fist, grip_tu, ready_td). The take has no such
// frames; which take frames stand for those poses is the owner's call, not made here. Until then the
// hands draw frame 0 (FrameIndex below) and the log says "pose targets not mapped yet".
//
// SIZE: THE HAND PATH IS IN METRES (vr_handpose.cpp VRHandPose_HandFrame: the grip frame is multiplied
// by VR_UnitsPerMeter() at every draw and never divided back), so Scale is metres per FILE unit. The
// file says centimetres but its hand is 1.712605 units from the wrist (Root_joint) to the farthest
// vertex of the middle fingertip (the vertices whose largest weight is MIDDLE_F_TOP/UP_TOP), measured
// by tools/fbxload_test (T5) on the rest mesh, the same measure the old converter used. For the hand
// to be 0.19 m: 0.19 / 1.712605 = 0.11094212, at whatever units per metre the level has.
//
// SKIN. Hand_Low's own material (aiStandardSurface1) names lambert1_Base_Color.png, and the engine
// finds it beside the file; no Skin line is needed. Hand_Low1's material (blinn1) has NO texture in
// the FBX (a plain 0.5 grey), and its UVs are Hand_Low's mirrored (u -> 1 - u, to 0.0028), so the skin
// texture lands on the wrong places on it (a nail on the palm: tools/fbxload_test/render.py, seen in a
// software render, not in the engine). The Skin line below is there so the left hand is drawn at all;
// what the left hand should wear is an open question for the owner.
//
// No Offset or angle offsets: the engine seats the mesh from its own wrist and knuckles
// (vr_handpose_math.h ModelSeat). NoPixelStretch: the grip frame already carries the world's pixel
// stretch. NoAutoReverse: each hand is its own mesh.

Model RealmsHandRight
{
	Path "models/hands"
	Model 0 "hand_final.fbx:Hand_Low"
	Scale 0.11094212 0.11094212 0.11094212
	NoAutoReverse
	NoPixelStretch
	FrameIndex RHDR A 0 0
}
